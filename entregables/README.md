**Cómo se relacionan.** E1 plantea la pregunta (¿cómo se extienden las features de DINOv3 a Marte?) y mide un primer teardown. Entre E1 y E2 se hizo el estudio capa por capa
(`results/final_run/`). Luego la pregunta se reformuló en tres preguntas, P1 datos, P2 modelo y P3 errores (estudio v2, `results/v2_full/`), y el póster, el resumen y el artículo
se actualizaron a esa versión. Las versiones anteriores se conservan para mostrar la evolución del trabajo.

El código, los resultados y la guía para leerlo están fuera de esta carpeta: ver el [README principal](../README.md).
